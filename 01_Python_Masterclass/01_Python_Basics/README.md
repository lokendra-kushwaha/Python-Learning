## 🚀 Highlights of this Module

* **Variables are NOT Boxes:** In Python, variables are not memory containers (boxes) that store data like they do in C/C++. Instead, they act as **'Labels' (or Sticky Notes)** attached to objects living in the memory.
* **The Memory Trade-off:** Python relies on Dynamic Typing. While this makes the syntax incredibly developer-friendly, the hidden cost is that every object behind the scenes consumes **3 to 5 times more RAM** compared to C!
* **Primitive Datatypes Under the Hood:** A deep dive into how `int`, `float`, `str`, and `complex` numbers are actually stored in memory, and the real reason why Python fails at simple math like `0.1 + 0.2`.
