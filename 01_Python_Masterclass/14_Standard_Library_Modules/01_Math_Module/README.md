# 📐 The math Module: High-Performance Mathematics

## 📌 Overview
The math module provides access to the mathematical functions defined by the C standard. Since it is implemented in C, it is highly optimized and significantly faster than writing custom mathematical logic in pure Python.

## 🚀 Core Capabilities
*   **Mathematical Constants:** Built-in values for Pi (math.pi), Euler's number (math.e), and Infinity (math.inf).
*   **Rounding & Truncation:** Precise control over floating-point numbers using ceil(), floor(), and trunc().
*   **Advanced Computations:** Factorials, Greatest Common Divisor (GCD), Least Common Multiple (LCM), powers, and square roots.
*   **Trigonometry:** Functions for Sine, Cosine, and Tangent, along with degree-to-radian conversions.

> **Architect's Note:** Always prefer math module functions over custom loops for heavy calculations to leverage C-level execution speed.
