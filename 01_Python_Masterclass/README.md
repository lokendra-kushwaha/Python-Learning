# 🎓 01_Python_Masterclass: The Complete Journey

Welcome to the **01_Python_Masterclass** directory! 

This is the core curriculum and the ultimate reference guide for my Python journey. It is structured to take concepts from absolute basics to advanced, production-level programming.

## 🏛️ Architecture: The docs & src Split
Unlike standard practice folders, this masterclass is organized like a professional software repository. Inside the topics, the content is cleanly separated:
*   **docs/**: Contains all the theoretical notes, logic breakdowns, and concept explanations.
*   **src/**: Contains the actual executable Python scripts (source code) that demonstrate the concepts in action.

## 📚 The Curriculum Roadmap
The directory is sequentially numbered to map out a clear, step-by-step learning path:
*   **Phase 1: The Core (01 - 04):** Python Basics, Control Flow, Data Structures, and Functions.
*   **Phase 2: Intermediate Mechanics (05 - 08):** Object-Oriented Programming (OOP), File Handling, Exception Handling, and Decorators.
*   **Phase 3: Advanced Engineering (09 - 13+):** Recursion, Generators, Concurrency/Parallelism (Multiprocessing & Threading), and Advanced Modules.

## 🚀 Dynamic Growth
This is a living masterclass. As I dive deeper into Python's ecosystem, this roadmap will continue to expand. It serves as a permanent, well-documented reference library that I can look back at whenever I am building complex projects.
