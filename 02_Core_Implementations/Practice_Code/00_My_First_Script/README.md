# 🕰️ Early Code Archive: The Pre-Loop Era

This folder contains the very first Python scripts I ever wrote. It is preserved exactly as it was created to serve as a baseline for how far my logical and syntactical understanding of programming has evolved.

## 💡 What's Inside?
A CLI Calculator application built in two distinct phases of learning:

1. **The `if-else` Version:** My initial attempt at handling user inputs and mathematical operations using basic conditional statements.
2. **The `match-case` Version:** My early exploration into Python 3.10's structural pattern matching.

## 🤣 The "Loop-less" Brute Force
The highlight of this script is how I handled the program's continuation before knowing how `while` or `for` loops worked. 

Instead of wrapping the core logic in a loop, I simply **copy-pasted the entire `match-case` block multiple times**, leaving behind the completely self-aware comment: 
> *"More Same Match Case Statement because I didn't use For or While Loop"*

This code isn't about best practices—it's a testament to raw problem-solving and the developer mindset: *if you don't know the tool, build it by hand!*
