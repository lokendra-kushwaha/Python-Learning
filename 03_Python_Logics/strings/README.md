# 🧵 String Methods from Scratch

Welcome to the **strings** directory!

Python makes text manipulation incredibly easy with its rich set of built-in string methods. But how do they actually work under the hood? This folder contains my custom, from-scratch implementations of these text processing tools.

## 🎯 The Goal
To manually parse, slice, and manipulate text data using raw iteration and basic indexing. The rule here is strict: no built-in string methods allowed. If text needs to be stripped, counted, found, or replaced, it is done logically, character by character.

## 💡 Dynamic Growth
Whenever I encounter an interesting string manipulation method, I reverse-engineer it and drop the custom logic here. This space serves as a constantly expanding library of manual text-parsing algorithms and logic-building experiments.
