# 🧮 Matrix Operations (Version 1.0)

This folder contains my very first foundational attempt at writing a Python class for Matrix mathematics. It is the starting point of one of my biggest learning curves in coding.

## 📖 The Evolution Story

This code represents **Phase 1** of a 3-part journey:

*   **Phase 1: The 2x2 Hardcoded Era (This Code):** I started by strictly handling 2x2 matrices using hardcoded variables (`a11`, `a12`, etc.). It worked flawlessly for basic Addition, Subtraction, and Multiplication, but it returned formatted strings, meaning I couldn't perform chained calculations.
*   **Phase 2: The 1D List Struggle:** I tried to upgrade the program to handle $n \times n$ matrices using 1D lists. While Addition and Subtraction worked fine (since they run in parallel), Multiplication completely failed. The project hit a roadblock.
*   **Phase 3: The 2D List Breakthrough:** After taking a break, the idea of using 2D lists clicked. I rewrote the logic, and not only did $n \times n$ Multiplication work, but I also successfully implemented Matrix Determinants and Inverses! Most importantly, I changed the return types from strings to **Matrix Objects**, allowing for infinite chained calculations.

## 💡 Why Keep This Version?
I am preserving this Version 1.0 script because it perfectly captures my raw problem-solving process. It reminds me that every complex, dynamic system (like my final $n \times n$ matrix program) starts as a simple, hardcoded idea.
