# ⚖️ Number Comparator Logic

A fundamental Python script designed to compare two integer values and determine their relational state (Greater, Lesser, or Equal). 

## 💡 About The Logic
This program acts as a core exercise in understanding Python's relational operators and conditional control flow. It securely takes two numbers from the user and passes them through a clean `if-elif-else` block to evaluate the mathematical relationship between them.

## 🛠️ Technical Highlights
* **Input Validation:** Utilizes a custom `get_valid_integer()` helper function to ensure the user inputs valid numbers, preventing the program from crashing due to `ValueError`.
* **Relational Operators:** Demonstrates the practical use of equality (`==`) and comparison (`>`) operators.
* **String Formatting:** Uses Python's dynamic `f-strings` to generate clean, readable, and highly formatted terminal outputs showing both the "greater than" and "lesser than" perspectives simultaneously.

**Lesson Learned:** A perfect foundational project for mastering control flow branching based on mathematical conditions!
