# 📊 Top Two Numbers (Single Pass)

Welcome to the **Top_Two_Numbers** logic folder!

## 🧠 The Concept
This directory focuses on extreme value extraction (finding the largest, second largest, smallest, etc.) from a dataset using the most efficient logical pathways possible.

## ⚙️ How It Works
The standard way to find extreme values is to use built-in functions like max() or to sort() the entire list first (which takes O(N log N) time). 
The algorithms in this folder avoid those shortcuts. Instead, they use a **Single Pass (O(N) time complexity)** approach. By using multiple tracking variables during a single iteration, the logic dynamically updates the primary and secondary extremes on the fly without modifying the original data structure.

## 🚀 Dynamic Growth
Future scripts in this folder will explore finding top 'K' elements, handling negative boundaries, and extracting extremes from multidimensional arrays.
