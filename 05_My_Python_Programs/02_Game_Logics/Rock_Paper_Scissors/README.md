# 🪨📄✂️ Rock, Paper, Scissors Game

Welcome to the classic Rock, Paper, Scissors game built in Python! This is a simple, command-line based game where you can test your luck against the computer.

## ✨ Features
* Play against the computer for a customizable number of rounds (Default is 5).
* Clean and interactive command-line interface.
* **Score Tracking & Logging:** Automatically saves your match history and final scores to a `score_history.txt` file.
* Handles invalid inputs gracefully without wasting your chances.

## 🚀 How to Run
1. Make sure you have Python installed on your system.
2. Clone this repository or download the python script file.
3. Open your terminal or command prompt in the same folder.
4. Run the following command:

```bash
python rock_paper_scissors.py
```

## 🎮 How to Play
When prompted, enter your choice:
* Type **Rock** (or just **R**)
* Type **Paper** (or just **P**)
* Type **Scissors** (or just **S**)
* Type **Exit** to quit the game at any time.

After the game ends, check the `score_history.txt` file in the same folder to see your match record! Enjoy the game! 🎉
